# Управление товарами и категориями

Проект реализует систему управления товарами интернет-магазина с поддержкой различных типов продуктов и категорий. Включает строгую проверку типов при операциях с товарами.

---

## Основные классы

### `Product` (абстрактный)

Базовый класс для всех товаров.

#### Атрибуты:
- `name` (`str`) — название
- `description` (`str`) — описание
- `price` (`float`) — цена (с защитой от отрицательных значений)
- `quantity` (`int`) — количество на складе

#### Особенности:
- Абстрактный метод `__add__`
- Классовый метод `new_product` для создания экземпляров
- Строковое представление товара

```python
product = Product.new_product({
    "name": "Телевизор", 
    "description": "4K HDR",
    "price": 59999.0,
    "quantity": 5
})

Category
Управление категориями товаров.

Атрибуты:
name (str) — название категории

description (str) — описание

_products (list[Product]) — список товаров

Особенности:
Автоматический подсчет:

category_count — всего категорий

product_count — всего товаров

Защита от добавления не-товаров

Строковое представление категории

python
smartphones = Category("Смартфоны", "Мобильные устройства")
smartphones.add_product(iphone)
